Project Overview & Development Role

Afsha Enterprises (www.afshaenterprises.com) is a high-conversion, full-scale E-Commerce web application engineered by Manish Kumar (Java Full Stack Developer).

The platform specializes in online retail of premium electric body massagers, neck & back pain therapy devices, and personal health equipment with automated cart management, order billing, and secure Razorpay payment gateway integration.

Key Features Engineered by Manish Kumar

  • Razorpay Payment Gateway: Seamless online checkout flow supporting UPI, Credit/Debit cards, Net Banking, and instant payment validation webhook APIs.
  • Product Catalog Management: Responsive, high-speed product catalog with category filtering and dynamic pricing calculation.
  • REST API Backend Architecture: Robust Spring Boot microservice architecture managing user sessions, cart operations, order statuses, and MySQL inventory persistence.
  • High-Speed & SEO Optimization: Engineered for sub-second initial page load speed, mobile responsiveness, and high Google search ranking for www.afshaenterprises.com.
