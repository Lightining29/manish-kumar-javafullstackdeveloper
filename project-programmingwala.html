Project Overview & Architectural Role

ProgrammingWala (www.programmingwala.com) is an end-to-end Learning Management System (LMS) and IT coaching portal engineered by Manish Kumar during his Java Full Stack Developer internship at Appletree Infotech.

Built on the MERN Stack (MongoDB, Express.js, React.js, Node.js), the platform delivers interactive online coding courses, student portals, automated enrollment tracking, and structured lecture materials.

Key Features Engineered by Manish Kumar

  • MERN Architecture: Full stack JavaScript solution using MongoDB for document persistence, Express/Node.js REST backend, and dynamic React JS frontend UI.
  • Student Course Portal: Course catalog, interactive video lessons, student registration, and progress tracking dashboard.
  • Secure Authentication: JWT token authentication and role-based access control for students and course instructors.
  • High-Performance Delivery: Optimised client-side rendering and cached REST API responses for fast load speeds on www.programmingwala.com.
